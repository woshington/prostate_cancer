% Abstract (Do not insert blank lines, i.e. \\) 
\abstract{The automatic classification of ISUP grade groups in prostate histopathological images is a challenging problem due to high similarity between adjacent classes, dataset imbalance, and label noise. This work proposes a pipeline based on EfficientNet convolutional neural networks combined with a hybrid loss function that integrates ordinal regression and Focal Loss. Initially, a noise-filtering strategy based on the entropy of predictions from multiple EfficientNet models was applied, thereby identifying samples with high uncertainty in the training set. Subsequently, the problem was modeled as an ordinal regression task to capture the hierarchical relationship among ISUP grades. The experiments were conducted using the PANDA dataset. The results demonstrate that removing noisy samples improved the baseline model's performance from $\kappa = 0.826$ to $\kappa = 0.833$. Using an ordinal loss further improved performance, yielding $\kappa = 0.851$. The best configuration, combining ordinal loss and focal Loss, achieved $\kappa = 0.857$ and an accuracy of $0.669$, while also reducing errors between distant classes and concentrating confusions among adjacent grades.}
