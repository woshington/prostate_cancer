PARÂMETROS COMUNS A TODOS OS MODELOS:
======================================
- Seed: 42
- Workers: 4
- Output classes: 5 (thresholds ordinais, exceto C2-5 com 3 e TTA com 5 direto)
- Warmup: 1 época com fator 2
- Scheduler: CosineAnnealingLR após warmup
- Optimizer: Adam
- Patience (Early stopping): 7 épocas (exceto TTA com 5)
- Data augmentation: Transpose, VerticalFlip, HorizontalFlip (p=0.5)
- Entropy filtering: Remoção dos top 20% amostras de maior dificuldade (exceto TTA)

OBSERVAÇÕES IMPORTANTES:
========================
- B0-TTA é o ÚNICO modelo que NÃO usa ordinal loss (usa BCEWithLogitsLoss)
- B0-TTA é o ÚNICO modelo que NÃO usa entropy filtering
- B0-TTA usa batch size 6 (todos os outros usam batch size 3)
- TTA é aplicado apenas durante inferência/teste, não durante treinamento

DETALHES ADICIONAIS POR MODELO:
================================

1. B0-Entropy-Ordinal:
   - Loss: OrdinalRegressionLoss (BCE ordinal)
   - Sem focal loss nem balanceamento

2. B0-Entropy-Ordinal-Focal:
   - Loss: OrdinalFocalLoss
   - Focal alpha: 0.25 (constante)
   - Focal gamma: 2.0

3. B0-Entropy-Ordinal-Focal-2:
   - Loss: OrdinalFocalLoss com alpha variável
   - Focal alpha: [0.25, 0.35, 0.50, 0.70, 0.90] (por threshold)
   - Focal gamma: 2.0

4. B0-Entropy-Ordinal-Weighted:
   - Loss: OrdinalRegressionLoss
   - Sampler: WeightedRandomSampler (balanced)
   - Class weights: [0.6036, 0.6542, 1.3113, 1.4272, 1.4169, 1.5491]

5. B0-Entropy-Ordinal-SWA:
   - Loss: OrdinalRegressionLoss
   - SWA start: época 30
   - SWA learning rate: 1e-4
   - Update BN statistics após cada época SWA

6. B0-Entropy-Ordinal-Focal-Deformable:
   - Loss: OrdinalFocalLoss
   - Deformable convolutions: Habilitadas nas últimas camadas
   - Total params: 18,970,771
   - Trainable params: 18,905,121

7. B0-Entropy-Ordinal-Focal-Classes-2-5:
   - Loss: OrdinalFocalLoss
   - Classes: Apenas ISUP 2, 3, 4, 5
   - Remapeamento: 2→0, 3→1, 4→2, 5→3
   - Output classes: 3 thresholds

8. B3-Entropy-Ordinal-Focal:
   - Backbone: EfficientNet-B3
   - Loss: OrdinalFocalLoss com alpha variável
   - Focal alpha: [0.25, 0.35, 0.50, 0.70, 0.90]

9. B7-Entropy-Ordinal-Focal:
   - Backbone: EfficientNet-B7
   - Loss: OrdinalFocalLoss
   - Focal alpha: 0.25 (constante)

10. B0-TTA (Test-Time Augmentation):
    - Loss: BCEWithLogitsLoss (NÃO ordinal)
    - Batch size: 6 (maior que outros modelos)
    - Patience: 5 épocas
    - SEM entropy filtering (treina com dataset completo)
    - TTA com 5 transformações durante inferência:
      1. Imagem original
      2. Horizontal flip
      3. Vertical flip
      4. Horizontal + Vertical flip
      5. Transpose
    - Predição final: Média das 5 predições
    - Output: 5 classes (não ordinal, classificação direta)

11. Ensemble-Mean:
    - Modelos: B0-Focal, B3-Focal, B7-Focal
    - Método: Média simples das probabilidades
    - Pesos: [0.27, 0.45, 0.27] (weighted variant)
    - Outros métodos testados: max, majority vote
